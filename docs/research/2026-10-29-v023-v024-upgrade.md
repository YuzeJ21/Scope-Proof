## Reproduction and ongoing regression

The old-writer recipe requires an explicitly selected external v0.2.3 environment and refuses
to replace an existing record or run under v0.2.4. After verifying the public assets above,
run from an external working directory, substituting absolute paths:

```sh
/path/to/v023-env/bin/python -I /path/to/checkout/tests/fixtures/released_v023_upgrade/generate_record.py \
  --env-prefix /path/to/v023-env --output-dir /path/to/new-disposable-output
```

Fresh generation uses fresh timestamps and therefore does not reproduce the retained byte hash.
Use the committed native bytes for the offline regression:

```sh
uv run pytest tests/storage/test_released_v023_upgrade.py -q
```

All four tests also passed under the isolated published v0.2.4 interpreter with pytest 9.2.0,
from outside the checkout. To repeat that check after verifying/installing the wheel, install
pytest in that disposable environment, verify its imported core is v0.2.4 under that environment,
then run from an external directory:

```sh
/path/to/v024-env/bin/python -I -m pytest \
  /path/to/checkout/tests/storage/test_released_v023_upgrade.py \
  --import-mode=importlib --confcutdir=/path/to/checkout/tests/storage -q
```

The normal repository invocation targets the active development reader (`0.2.5.dev0` at branch
start), requires no network or old-package installation, and asserts the same native record's
preserved and conservative behavior. Published-reader and current-reader results remain separate.
The Windows compatibility lane explicitly includes the four regressions. Full-suite,
coverage, compatibility, packaging and browser results belong to the PR's exact-head hosted
checks and resulting-main checks, rather than this released-package observation.

## Limits and operating decision

Keep backups of existing records and original exports before an upgrade. A retained historical
acceptance decision does not resolve missing changed-file scope, confirm a current head or
establish correctness. This case does not establish malformed-record recovery, universal
upgrade compatibility, downgrade compatibility, live GitHub operation, platform coverage,
accessibility conformance or independent use.

The native-producer regression closes the named question after independent engineering review
and required checks. Return to bounded maintenance. Public install remains v0.2.4; source remains
unreleased `0.2.5.dev0`. No release, deployment or outreach follows. Stage 1 remains closed at
zero external-evidence credit; Stage 3 remains dormant until genuine independent-use evidence
and separate authorization exist. Personal testing and qualifying reviews are not requested.
