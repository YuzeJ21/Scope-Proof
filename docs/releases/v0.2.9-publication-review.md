## Release notes prepared for review

ScopeProof helps a reviewer inspect acceptance evidence for confirmed criteria on public
GitHub pull requests. External CI context remains separate from criterion evidence, human
acceptance and the deterministic gate.

Changes since public v0.2.8:

- Export an exact-build CI snapshot from a named saved review with `scopeproof ci-snapshot`,
  using an explicitly supplied local manifest. Preserve inputs and refuse stale, incompatible,
  pending or existing outputs.
- Show CI follow-up in the workbench and offline snapshot: one entry for each unresolved test,
  mapped criterion IDs and cited runs, plus criteria with no expected test mapping.
- Read the maintained no-install two-build walkthrough. It reuses original constructed reports
  and inputs with simulation disclosures and next reviewer actions; it supplies no real-use evidence.
- Compare two supplied CI manifests for the same reviewed commit with `--previous-manifest`.
  Inspect changed effective results, mappings and run assertions with both input digests.
- Compare current and previous CI inputs in the workbench and download the offline comparison.
  Both exact input bytes and the active review bind the download; changed inputs and pending
  review drafts invalidate older controls.
- See previous/current reported run outcome maps inline, including empty maps, missing runs
  and run changes that retain the same effective test result.
- Retain an unpublished exact-source evaluation packet only after archive/source inventory,
  test-report and installed-wheel bindings validate.

Saved-record format remains v9, ruleset 2.0.0 and use policy evaluation-only. Existing records
retain their recorded producers and analyses; a new package version does not rewrite historical
verification. Frozen R-002 and maintained report/input bytes are unchanged. No generic code
review, security-scanning or auto-fix feature is introduced.

## Obtain and review the fresh final-version packet

Use the successful **main** CI run and artifact linked in the enclosing final-source preparation
PR. That PR records actual full source commit/tree, run attempt, verification counts, artifact
identity and both archive hashes after hosted CI finishes. A PR merge packet is a preview;
it cannot substitute for the separately rebuilt main packet.

Expected files in the five-file CI packet:

| File | Review purpose |
| --- | --- |
| `scopeproof-0.2.9-py3-none-any.whl` | Fresh final-version wheel used by installed CLI checks. |
| `scopeproof-0.2.9.tar.gz` | Fresh source archive rebuilt to a byte-identical wheel. |
| `SHA256SUMS.txt` | Exact SHA-256 values for both archives. |
| `candidate.json` | Strict source/event/run, archive, test and installation bindings; publication remains `unpublished`. |
| `README.md` | Consumption instructions and evidence limits. |

Require successful aggregate CI and the corresponding CodeQL workflow. Inspect `candidate.json`:
`source_kind` must be `main`, `version` must be `0.2.9`, and commit/tree/run/attempt must match the
preparation PR. Verify archive bytes against checksums before use. The final builder refuses
old development archives without changing them or creating a packet. Artifacts have 90-day
retention and are not permanent Release downloads or signed provenance.

The existing workflow verifies actual source/rebuilt wheel equality, complete wheel and tracked
source-archive Python inventories, the installed CLI wheel, every numbered browser-fixture wheel,
source/browser JUnit observations, and a source-wheel install/benchmark probe. That probe inherits
tested CI dependencies; it is package isolation, not a second clean dependency resolution.
Compatibility lanes have their own source/package observations. They do not claim every platform
installed the exact retained Linux wheel bytes. Raw outcome values are asserted in AppTest;
browser journeys verify the installed comparison flow and view availability, not canvas cell text.
The previously documented helper output-path/probe-field refinements remain deferred; the actual
workflow supplies an outside output path and valid boolean/environment values.
