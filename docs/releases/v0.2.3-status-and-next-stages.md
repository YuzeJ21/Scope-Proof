## What the product does

ScopeProof helps a PM, QA practitioner, or engineer inspect whether a public
GitHub pull request contains credible candidate evidence for each explicitly
confirmed acceptance criterion at an exact PR head.

The workflow is:

1. load a public PR or the deliberately constructed demo;
2. normalize and explicitly confirm acceptance criteria;
3. deterministically retrieve candidate implementation and test evidence;
4. inspect cited lines and explanations for missing candidates;
5. record human decisions and optional external runtime verification;
6. fail closed unless all current evidence and decision gates are satisfied;
7. save, reopen, compare changed heads, and revisit affected decisions; and
8. export Markdown, JSON, CSV, or HTML evidence records.

It does not prove correctness, execute target code, replace QA, generate generic
code-review comments, scan security, or automatically fix a PR.

## Primary use cases

1. **Pre-merge acceptance-coverage review:** inspect which confirmed criteria
   have credible implementation or test candidates and which require more work.
2. **PM/QA-to-engineering handoff:** export a criterion-by-criterion record that
   keeps missing evidence and unresolved decisions visible.
3. **Changed-head re-review:** compare immutable prior and current candidates
   and revisit decisions affected by a new SHA.
4. **False Ready prevention:** refuse a Ready result when ingestion, checks,
   evidence, runtime requirements, or current human decisions are incomplete.
5. **Public engineering research:** run deterministic, hash-bound static cases
   without executing target repositories.
